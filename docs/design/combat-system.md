# 数值体系 · 装备 · 伤害引擎

## 1. 道行等级（对标标尺）
人物与灵兽统一用「道行 Lv」度量：Lv = 境界序×9 + 层数（每层 1~9）。
练气一层 Lv1 … 筑基 Lv10~18 … 大乘圆满 Lv72+。

## 2. 人物面板
| 属性 | 公式 |
|---|---|
| 攻力 ATK | 22 + Lv×3 + 剑攻击 |
| 术强 SP | 30 + Lv×4 + 饰攻击 |
| 防御 DEF | 8 + Lv×2 + 袍防御 |
| 气血 HP | 100 + Lv×12 + 袍/饰气血 |
| 真元 MP | 100 + Lv×5 + 饰真元 |
| 暴击 | 5% + 词缀 |

## 3. 灵兽等级
灵兽生成时按玩家当前道行定级：Lv怪 = 玩家Lv + 随机(-3 ~ +4)，钳制 ≥1。
血/攻随级缩放：hp = 基础 × (Lv/5)，攻 = 基础 × (Lv/5)，修为/灵石掉落 ×(Lv/5)。
血条标注「名 · Lv.n」，等级高于玩家 9+ 显示红色、低 9+ 灰色。

## 4. 破防规则（修为差距）
攻方对守方造成 raw 后先过防御：dealt = raw × 100/(100+守防)。
再按等级差修正：
- 怪Lv − 人Lv ≥ 18（差两境界）：玩家伤害 ×15% → 飘字「无法破防」；怪物攻击 ×1.8 → 飘字「境界碾压」
- 差 ≥ 9（一境界）：玩家伤害 ×50%
- 人Lv − 怪Lv ≥ 18：怪物攻击 ×50%（玩家碾压）
暴击：×1.5，金色飘字。

## 5. 装备
槽位：佩剑（攻）、法袍（防+气血）、玉佩（术强+真元）。
品阶五等：凡品(白)→灵品(青)→玄品(蓝)→地品(紫)→天品(金)，权重 40/30/18/9/3，
怪物 Lv 越高，高品阶权重越大（Lv≥30 才可能掉天品）。
属性：主属性 = 底值(按品阶×掉落时怪物Lv) ± 10% 浮动；词缀 1~2 条
（攻+X%、防+X%、气血+X、修为获取+X%、暴击+X%）。
掉落：击杀 35% 概率掉一件，品阶按上表；拾取入装备囊，行囊内点击穿/卸。
