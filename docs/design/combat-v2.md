# 战斗体系 v2 设计 · 动漫式大招与施法

目标：把现在"瞬发小技能"升级成有节奏、有演出、有取舍的修仙战斗——小技能风筝消耗 → 积势 → 大招爆发，Boss 有阶段有读条。

## 1. 战斗循环（动漫节奏）
```
剑气/走位（攒势）→ 小技能压制（耗真元）→ 战意值满 → 大招（演出+高伤）
                                     ↘ 防御侧：罡气格挡 / 遁光闪避（无敌帧）
```
- 新增资源「战意」0~100：造成伤害 +6、受击 +3、击杀 +20；脱战 8s 后每秒 -5。
- 大招键 R，耗全部战意。真元只管小技能。

## 2. 技能结构（按灵根各配一套，先做金系通用版）
| 键 | 技能 | 类型 | 演出 |
|---|---|---|---|
| 左键 | 剑气 | 瞬发普攻 | 剑光飞刃+拖尾 |
| 1 | 剑雨 | 引导 0.5s | 落剑阵 |
| 2 | 雷符 | 读条 1.2s（可被打断） | 天降雷柱 |
| 3 | 罡气 | 瞬发防御 | 护盾壳 |
| 4 | 遁光 | 瞬发位移 | 0.15s 无敌帧+残影 |
| R | **大招·万剑归宗** | 蓄力爆发 | 定格特写+剑阵洗地 |
| T | **法域·灵压阵** | 领域（30s CD） | 脚下法阵扩散，域内增伤减速 |

## 3. 大招「万剑归宗」演出分镜（约 3.2s）
1. **起手 0.4s**：时间减速 0.3×（子弹时间），镜头拉近推到角色背后，角色浮空 1.5m，周身剑气环绕汇聚
2. **蓄力 0.8s**：36 柄灵剑在身后螺旋展开成剑轮，真元柱冲天，画面边缘泛金色暗角（vignette）
3. **爆发 1.2s**：剑轮炸裂，灵剑分批砸向锁定区域（每 0.08s 一批 4 柄），落点剑光爆+地面裂纹贴花+屏幕震动(shake 0.4)
4. **收尾 0.8s**：残余剑影化为光点飘散，时间恢复正常，镜头回位
- 伤害：对半径 12 内敌人造成攻力×4.5 + 每柄命中附加 0.3×（读条不破防规则不变）
- 打断：起手期被打断只返还 40% 战意

## 4. 施法系统（读条/结印）
- **读条**：雷符改为 1.2s 吟唱，屏幕下方出金色读条，受击打断（扣真元不扣 CD）
- **结印手势**：吟唱时角色双手程序化骨轮动结印动画（已有骨骼方案可复用打坐的实现），掌心生符文光球随读条变大
- **施法锁定**：读条期间移动速度 -70%，可主动按技能键取消
- 瞬发类不变（剑气/罡气/遁光）

## 5. 领域「灵压阵」
- 以自身为中心展开半径 10 的金纹法阵（地面发光阵纹+边界光柱+漂浮符文）
- 域内自身：攻力+30%、真元回复×2；敌人：移速-40%
- 持续 12s，CD 30s；离开领域效果即消

## 6. Boss / 精英体系
- **精英怪**：普通怪 8% 概率出「凶兽」前缀（Lv+6、体型×1.4、红名），必掉装备+高品阶权重
- **Boss**（先做一只）：「千年玄蛟」盘踞灵湖深处
  - 阶段一：普通扑咬+甩尾（近战圈）
  - 阶段二（60% 血）：召唤 3 道水龙卷（持续 AoE，躲柱子状安全区）+ 读条「蛟吟」全屏波（需要遁光/罡气应对）
  - 阶段三（25% 血）：狂暴攻速+50%，鳞片泛红
  - Boss 血条置顶横幅（名字+大血条），击杀全屏"斩杀"金字+必掉地品/天品装备
- Boss 读条技：头顶显示读条圈，给玩家 1.5s 反应窗口

## 7. 特效技术方案（全部程序化，不引外部资源）
| 效果 | 实现 |
|---|---|
| 灵剑实体 | 细长 Box+发光刃纹贴图，替代现在纯光弹（写实化一致风格） |
| 剑轮 | InstancedMesh 36 实例，绕角色旋转矩阵 |
| 读条 | HUD 底部 DOM 进度条+掌心生 glow sprite 缩放 |
| 子弹时间 | clock 时间缩放系数：dt *= timescale（大招期 0.3） |
| 屏幕震动 | camera 位置叠加衰减噪声偏移 0.3s |
| 地面裂纹 | 生成裂纹贴花 Plane（程序化 canvas 裂纹纹理），淡出 |
| 法阵 | 既有 altar 阵纹贴图复用放大+旋转，边缘 RingGeometry 光柱 |
| 水龙卷 | 螺旋顶点扭曲圆柱+粒子上升 |
| 斩杀横幅 | HUD 全屏金字大字+墨刷底纹，1.8s 淡出 |
| 残影 | 遁光时克隆当前模型半透明残影 3 帧淡出 |
| 暗角 | hurt-vignette 同款 DOM 层，大招期金色版本 |

## 8. 数值接入
- 大招/领域伤害都走 calcDamage 引擎（破防/碾压/暴击不变）
- 战意、读条状态存入玩家对象，不进存档（战斗态不持久）
- Boss 属性用 beastStats 放大：hp×20、atk×3、def×4，独立技能冷却
