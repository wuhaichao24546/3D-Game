# 《云游修仙》功能设计文档

> 定位：真实 3D 玄幻修仙开放世界（写实人物比例 + 玄幻灵效），浏览器直接可玩，Three.js + Vite。

## 一、核心循环

```
探索大世界 → 采集/猎兽/奇遇 → 获取修为与材料 → 打坐炼化 → 突破境界
     ↑                                                ↓
     ←———— 解锁更强技能/法宝/神通，挑战更强妖兽与秘境 ←———
```

- 短期目标（5 分钟）：杀怪、采集、跑图看景
- 中期目标（半小时）：升层、学技能、做任务、炼一炉丹
- 长期目标（多次游玩）：境界突破、宗门晋升、神兽奇遇、飞升

## 二、角色系统

| 模块 | 内容 | 现状 |
|---|---|---|
| 形象 | 写实比例人物 + 墨青道袍金边 + 玉簪金冠 + 负剑 | 已有 |
| 外观自定义 | 创建角色时选发型/袍色/佩饰（3 套预设） | 新增 |
| 灵根 | 金/木/水/火/土 随机或自选，决定技能加成与修炼偏好 | 新增 |
| 移动 | 走/疾跑/跳跃/御剑飞行 | 已有 |
| 移动扩展 | 遁光（高速低飞拖尾）、缩地成寸（短距闪现）、踏水 | 新增 |

## 三、修炼与境界

### 3.1 打坐吐纳（已有 → 强化）
- 灵气光点汇聚 → 升级为**经脉周天运行**：角色身上浮现发光穴位连线，灵气沿任督二脉循环流动
- 灵脉节点加成：在灵湖阵眼/万年神树/祭坛等灵气浓郁处打坐，速度 ×2~×5
- 日夜加成：子时/午时（阴阳交替）修炼效率 +50%

### 3.2 境界体系
练气一层~九层 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → **渡劫飞升**

每层突破有独立事件：
- 小突破（层间）：光圈+横幅（已有）
- 大境界突破：**雷劫事件** —— 天空乌云汇聚、雷柱轰顶，需硬抗（法宝/护体罡气）或走位闪避雷点；成功境界+1，失败重伤退回半层
- 心魔幻境（化神后）：进入独立小场景对战心魔化身

## 四、战斗系统

### 4.1 技能栏（1~6 键快捷栏）
| 槽位 | 技能 | 效果 |
|---|---|---|
| 左键 | 剑气 | 已有，远程光刃 |
| 1 | 御剑术·剑雨 | 范围落剑 |
| 2 | 雷符 | 召唤落雷，AoE |
| 3 | 护体罡气 | 护盾数秒 |
| 4 | 遁光 | 突进位移 |
| 5 | 法宝技 | 随装备法宝变化（飞剑穿刺/葫芦吸取/宝塔镇压） |
| 6 | 丹药快捷 | 快捷嗑药 |

技能耗**真元**（蓝条，打坐/丹药回复），有冷却与施法动作。

### 4.2 法宝
- 飞剑（攻）、玄葫芦（吸灵气/收妖）、玲珑塔（防+镇压）、山河印（重击）
- 获取：秘境掉落/炼器合成/神兽传承
- 养成：炼化升阶（喂材料），外观随阶变化（更亮符文）

### 4.3 灵兽 AI 与战斗
- 状态机：游荡 → 警觉 → 追击 → 攻击/技能 → 逃逸（低血）
- 仇恨：接近/被攻击触发；脱离范围回血
- 血条悬浮 + 伤害飘字 + 受击硬直
- 掉落：修为 + 灵石 + 材料（内丹/皮毛/妖骨）
- 精英变体：体型+30%、金色描边、掉稀有材料

## 五、神兽系统（已有模型 → 加交互）

| 神兽 | 位置 | 交互 |
|---|---|---|
| 青龙 | 云海高空 | 雨天现身盘旋；御剑追上有概率触发"龙吟赐福"（修为暴涨） |
| 火凤凰 | 灵湖上空 | 周期性涅盘事件：浴火重生时靠近捡取凤凰羽（顶级炼器材料） |
| 白虎 | 白虎崖 | 供奉妖兽内丹 → 概率获得"庚金虎魄"（武器附魔） |
| 麒麟 | 上古祭坛 | 修复祭坛法阵（支线）→ 麒麟认主，灵宠助战 |
| 白鹿/白狐 | 灵湖 | 可狩猎（已有）；幼崽可驯养为灵宠 |

**灵宠**：捕捉/赠予幼崽 → 跟随出战，喂食成长，3 阶进化外形变大变华丽。

## 六、大世界生态

- **昼夜/时辰**（已有）+ **天气**：晴/阴/雨/雷雨/雪；雷雨触发青龙现身与雷劫修炼加成
- **灵气浓度**：灵脉节点可视化（淡光流），浓度影响打坐效率与灵草刷新
- **采集**：灵草（炼丹）、灵果（即时修为）、矿石（炼器）、灵木（建造）
- **区域**：青溪村 / 山居草庐 / 上古祭坛 / 万年神树 / 灵湖阵眼 / 白虎崖 / 青竹幽谷 / 石质道宫 / 秘境洞府入口（已有）→ 新增宗门山门、坊市、荒古原野、坠星海

## 七、NPC 与任务

### 7.1 门派「青霄宗」
- 山门建筑群：牌坊、大殿、功法阁、丹房、器房、演武场
- 职位：外门弟子 → 内门 → 真传 → 长老；靠贡献点晋升
- 功能：接门派任务、兑换功法/丹方/器方、门派论剑（切磋）

### 7.2 村民/NPC
- 作息：日出而作日入而息，屋内外走动
- 对话：简单对话框（靠近按 E），关键词选项

### 7.3 任务
- **主线**（5 章）：凡人入道 → 拜入青霄 → 秘境试炼 → 正魔之争 → 渡劫飞升
- **支线**：村民委托（寻物/除妖/送信）、祭坛修复、神树祈福
- **随机奇遇**：洞中残卷、受伤高人托孤、灵兽报恩、天降陨铁

## 八、经济与背包

- **背包**：物品网格栏（B 键），分类：丹药/材料/法宝/功法/杂物，堆叠上限
- **装备位**：法衣（防）、佩饰（词条）、法宝 ×2
- **丹药**：回春散（回血）、聚灵丹（修为）、破障丹（破境辅助）、解毒丹
- **炼丹**：丹炉（丹房/洞府）+ 丹方 + 灵草 → 成功率受丹药品阶影响，炸炉概率
- **炼器**：器炉 + 器方 + 矿石/妖骨 → 法宝/飞剑
- **坊市**：灵石买卖 NPC，价格随供需浮动（简版固定价）

## 九、洞府

- 在秘境洞府入口开辟私人空间（独立小场景传送进入）
- 可布置：丹炉、器炉、灵田（种灵草定时收获）、蒲团（离线修炼积累）
- 洞府升级：灵气浓度→空间扩大→装饰

## 十、存档

- localStorage 自动存档（30s/切换场景）：境界/修为/背包/装备/灵宠/位置/时间/任务进度
- 登录页"继续修行"读档 / "重入轮回"新档

## 十一、音效

- 环境：鸟鸣/流水/风声/竹林沙沙（昼夜不同）
- 反馈：剑气破空、雷劫轰鸣、丹成叮咚、突破钟罄
- BGM：古筝/箫 循环背景曲（WebAudio 生成或免版权音源）

## 十二、远期（可选）

- 联机：WebSocket 同游（互见角色）、论剑切磋、组队秘境 —— 需要一台常开服务器
- 移动端：虚拟摇杆 + 触屏技能键
- 季节系统、结婚/师徒、转生轮回（飞升后属性加成重开）

## 技术约束备忘

- 浏览器性能：静态建筑 bake 合并、实例化植被、贴图程序化 canvas、Draco GLB；不做真 PBR/光追，靠 ACES tone mapping + 雾 + bloom 逼近"写实玄幻"
- 资源策略：程序化为先，关键角色/灵兽用免费 GLB + 自绘贴图
- 无后端：全部前端 + localStorage；联机才需要服务器
