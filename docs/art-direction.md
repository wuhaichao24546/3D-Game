# 云游修仙 · 美术方向（写实风格）

## 1. 总体风格

从低多边形卡通风 → **写实仙侠风**：真实比例人物、PBR 材质、真实光照与大气、日月昼夜循环。
参考概念图：`concept-character.png` / `concept-day.png` / `concept-night.png` / `concept-beasts.png`。

## 2. 角色（真实人物）

青袍束发修士：深色汉服宽袖、金色云纹镶边、玉簪发髻、背负长剑。

**实现路径**：
- 首选：接入真实绑定的 glTF 人物模型（免费授权资源，换装/重贴图为青袍风格）
- 备选：高精度程序化人物 + AI 生成贴图（皮肤/布料），比例真实、布料有体积感
- 飞剑：细长八面刃身 + 青色流光拖尾 + 符纹贴图

## 3. 自然环境（写实化）

- **地形**：更高细分度、平滑着色；AI 生成无缝贴图 — 草地/岩壁/泥土/滩涂按海拔坡度混合
- **水面**：真实水面着色器 — 法线扰动波纹、天空反射、近岸透明渐变、水波微光
- **植被**：远景用 AI 生成树的公告板（billboard），近景用有枝干层次的树；加草地贴图/零星花草点缀
- **浮空岛**：岩石质感 + 垂瀑粒子 + 岛顶殿阁剪影（概念图方向）
- **云**：半透明体积感云团，多层漂移
- **大气**：距离雾 + 山谷低空平流雾；ACES 色调映射保留

## 4. 昼夜循环（新增）

- 完整 24h 循环（游戏内约 10 分钟一圈，可调）
- **白天**：物理天空（Rayleigh 散射）、暖阳方向光、硬阴影感
- **黄昏**：金色低角度阳光、天空橙红渐变
- **夜晚**：满月 + 星空穹顶、冷色月光、灵气粒子/灵火更亮、灵兽眼睛微光
- HUD 显示时辰（子丑寅卯…十二时辰）

## 5. 特效

- 打坐：灵气螺旋汇聚（夜间发光更明显）
- 突破：金色冲击环 + 领域光柱
- 剑气：青白色飞剑形弹道 + 流光拖尾
- 灵兽：九尾狐尾尖蓝焰、玄龟苔藓玉纹、赤焰狼火星飘散（以生成贴图 + 粒子近似）

## 6. 性能约束

贴图控制在 1K–2K，植被用 instancing/billboard，粒子总量 <2000；目标普通笔记本 60fps。
